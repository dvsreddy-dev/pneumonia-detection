# 🫁 Pneumonia Detection from Chest X-Rays

Deep learning system that classifies chest X-rays as **pneumonia-positive** or **pneumonia-negative**, built on the [RSNA Pneumonia Detection Challenge](https://www.kaggle.com/c/rsna-pneumonia-detection-challenge) dataset. It serves as a clinical **decision-support / triage tool** — flagging likely pneumonia cases for priority radiologist review rather than replacing the clinician.

**🔗 Live app:** https://pneumonia-detection-nf8wnjckue4zbhq6jwwegj.streamlit.app/
**🤗 Model:** https://huggingface.co/dvsreddy/pneumonia-detection-model
